## 🎯 Cómo Generar una Licencia para un Cliente

### Opción 1: Clave Individual (Recomendada)

1. **Abre el panel admin**: `https://wa-gestor-app.pages.dev/?admin=true`

2. **Ingresa el nombre del cliente** (ej: "Juan Pérez")

3. **Ingresa el teléfono** (opcional, ej: "987654321")

4. **Haz clic en "Generar Clave Única"**

5. **Se genera una clave** como esta:
   ```
   WA-QUF1IG4g-OTg3NjU0-ABCD-1A2B3C4D
   ```

6. **Copia la clave** (botón 📋 Copiar)

7. **Envíasela al cliente por WhatsApp** después que te pague

---

### Opción 2: Lote de Claves (Para tener stock)

1. En el panel admin, ve a **"📦 Generar Lote de Claves"**

2. **Elige la cantidad** (1-50)

3. **Haz clic en "Generar X Claves"**

4. **Copia todas las claves** de una vez

5. **Úsalas cuando los clientes vayan pagando**

Ejemplo de claves generadas:
```
WA-PRO-A1B2C3D4-1A2B3C4D
WA-PRO-E5F6G7H8-5E6F7G8H
WA-PRO-I9J0K1L2-9I0J1K2L
```

## 🔍 ¿Cómo saber si una licencia es válida?

El sistema valida automáticamente el formato:
- ✅ Debe empezar con `WA-`
- ✅ Debe tener 5 partes separadas por guiones
- ✅ Cada parte debe tener 4 caracteres alfanuméricos
- ✅ Formato: `WA-XXXX-XXXX-XXXX-XXXX`

Si el cliente ingresa una clave inválida, verá:
```
❌ Clave inválida. Verifica el código que recibiste.
```
